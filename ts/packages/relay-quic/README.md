# @mux/relay-quic

The Relay SDK's transport adapter for Node. It carries MOQT straight on a QUIC connection (native QUIC, ALPN
`moqt-20`), through a napi-rs addon over [quinn](https://github.com/quinn-rs/quinn), so a plain Node script can publish
and subscribe without a browser. It follows the transport adapter contract in
[`spec/transport-adapter.md`](../../../spec/transport-adapter.md) and passes its conformance suite. The design is
[ADR 0002](../../../docs/adr/0002-node-adapter-speaks-native-quic.md).

The package is private for now: its prebuilt binaries are built and packed in CI, but not yet published (#195).

## Use

Most scripts need no code from this package: `@mux/relay/node` uses it by default, and takes the trust options below
(see the [SDK README](../../README.md#node)). Install it next to `@mux/relay`.

To use it with `@mux/relay` directly, pass the factory as `createTransport`. The URL stays the same `https://` endpoint the browser uses: the adapter dials
only its host and port, and the core sends the path, the token and the authority in SETUP.

```ts
import { connectRelayPublisher } from '@mux/relay';
import { nativeQuicTransport } from '@mux/relay-quic';

const publisher = await connectRelayPublisher({
  url: 'https://sjc.relay.mux.global',
  getToken: () => process.env.RELAY_TOKEN,
  createTransport: nativeQuicTransport(),
});
```

`nativeQuicTransport()` throws at once if the addon is missing for the platform or an option is invalid. Build it once
and reuse it for every connection.

## Trust

By default a dial trusts the platform's root certificates.

- `ca`: extra trust anchors, PEM, as a string, bytes, or an array of either. They are added to the platform's roots.
- `serverCertificateHashes`: `[{ algorithm: 'sha-256', value }]`, in the W3C WebTransport shape. The server's
  end-entity certificate must match one hash, and its chain is not validated. The handshake signature is still
  checked. Unlike a browser, the adapter does not require the certificate to be valid for 14 days or less.

## Process lifetime

An open session keeps the Node process alive, from the start of the dial until `closed` settles. After that the
adapter holds nothing: a script exits once it has closed its connections. Closing before the dial completes cancels
the dial and releases its socket.

## Prebuilt binaries

Each platform's binary ships in its own package, which `@mux/relay-quic` lists as an optional dependency, the napi-rs
convention. A package manager installs only the one whose `os`, `cpu` and `libc` match, so no Rust is needed.

| Platform package | Built on | Packed | Installed |
| --- | --- | --- | --- |
| `@mux/relay-quic-darwin-arm64` | macos-14 | 1.14 MiB | 2.62 MiB |
| `@mux/relay-quic-darwin-x64` | macos-14, cross | 1.21 MiB | 2.85 MiB |
| `@mux/relay-quic-linux-arm64-gnu` | ubuntu-latest, zig | 1.19 MiB | 2.67 MiB |
| `@mux/relay-quic-linux-arm64-musl` | ubuntu-latest, zig | 1.19 MiB | 2.67 MiB |
| `@mux/relay-quic-linux-x64-gnu` | ubuntu-latest, zig | 1.26 MiB | 3.01 MiB |
| `@mux/relay-quic-linux-x64-musl` | ubuntu-latest, zig | 1.26 MiB | 3.00 MiB |
| `@mux/relay-quic-win32-x64-msvc` | windows-latest | 1.26 MiB | 3.33 MiB |

Installed is what an install puts on disk on that platform: this package, `@mux/moq-core` and the one binary. The
sizes are from the 0.0.0 packages CI packed on 2026-10-01. The glibc builds need glibc 2.28 or later, which Node 24
needs too.

`src/addon.ts` loads a local build, `native/relay-quic.<platform>.node`, first, so a build from source always wins.
Without one it loads `@mux/relay-quic-<platform>`. If neither is there, the error names both. A platform package that is
installed but cannot load (a wrong libc, say) throws its own error rather than being skipped.

The `relay-quic binaries` workflow (`.github/workflows/relay-quic-binaries.yml`) runs on each PR that touches the crate,
the loader or the packaging. It builds every target, and `scripts/pack.mjs` packs the main package, the platform
packages and `@mux/moq-core`, with the sizes in the job summary. `scripts/smoke.mjs` then installs those tarballs with
npm on each platform (musl in Alpine, arm64 Linux under QEMU, darwin-x64 under Rosetta). It checks that npm picked only
the matching binary, that the loader finds it, and that a dial sends a QUIC Initial and can be cancelled. A `ts/v*` tag
or a manual run adds `napi pre-publish --dry-run`. Publishing to npm waits for the TS SDK's first release.

The platform packages live in `npm/<platform>/`, generated by `napi create-npm-dirs` from `napi.targets`. The
optional dependencies on them are added only when packing, so the lockfile never names unpublished packages.
`pnpm check:boundaries` checks that the two agree.

## Building the addon

To work on the crate, build the addon locally with Rust. The mise tasks bring the toolchain `mise.toml` pins; nothing
else in the repo installs one.

```sh
mise run ts:test:conformance:node   # builds the addon, then runs the conformance suite against it
mise run ts:check:native            # cargo fmt --check, clippy and the unit tests
mise run ts:build:native -- --target aarch64-unknown-linux-musl -x   # cross-compiles with zig, as CI does
```

With a Rust toolchain of your own, `cd ts && pnpm --filter @mux/relay-quic build:native` writes
`native/relay-quic.<platform>.node`. Cross-compiling with `-x` also needs `cargo-zigbuild` and the target's
`rustup target add`.

`build:native` also regenerates `src/native.d.ts`, the addon's typings, from the Rust. Commit it with any change to
the crate. CI checks that it matches.

`pnpm check` builds and checks the TypeScript only, so the rest of the workspace needs no Rust.

## Layout

| Path | What it is |
| --- | --- |
| `src/index.ts` | `nativeQuicTransport` and its option and result types. |
| `src/transport.ts` | The `MoqtTransport`: the dial, `ready`, `closed`, `close()` and the incoming streams. |
| `src/streams.ts` | WHATWG streams over the addon's stream halves. |
| `src/errors.ts` | The addon's failures as the contract's error shapes (TA-22). |
| `src/addon.ts` | Finds and loads the addon for this platform: a local build, else the platform package. |
| `native/` | The Rust crate: trust (`tls.rs`), stream halves (`stream.rs`), failures as data (`failure.rs`), the dial and the session (`lib.rs`). |
| `npm/<platform>/` | The platform packages, one per `napi.targets` entry; CI puts each binary in its own. |
| `scripts/pack.mjs`, `scripts/smoke.mjs` | Pack the release tarballs with their sizes; install and smoke-load them. |
